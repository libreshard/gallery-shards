## [1.1.0] - 2026-11-18

For LibreShard 0.5.1. The buttons, keys and settings are the same: if you set up the hotkeys in OBS
Studio before, they keep working.

### Changed

- Its name is now **Stream Control** (it was "OBS Studio", which looked like the program itself).
  Its id is still `obs`, so your settings, favorite and place in the menu stay.
- It moved out of LibreShard into the gallery: LibreShard 0.5.2 no longer includes it and offers to
  install it from there.

## [1.0.0] - 2026-11-02

Included with LibreShard from 0.1.0 to 0.5.1.
