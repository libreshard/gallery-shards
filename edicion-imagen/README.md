# Image editing

Tools, brush size, zoom, undo and save on your tablet, for Photoshop, Affinity Photo, Krita or GIMP,
with each program's default shortcuts.

> Unofficial: not affiliated with or endorsed by Adobe, Serif (Canva), the Krita Foundation or the
> GIMP project. It contains none of their logos.

## Use

1. Install the shard from LibreShard's gallery (**Shards → Explore the gallery**).
2. In its settings (LibreShard on the PC → **Shards → Image editing → Settings**), choose your
   program. The buttons then press that program's default shortcuts.

The shard only acts while one of those programs is in front. The help on the tablet (**?**) shows
which program is chosen.

Windows and Linux (Photoshop and Affinity Photo: Windows). See [CHANGELOG.md](CHANGELOG.md).
